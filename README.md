# 🐐 Hype Cut · Хурдан хэмнэл

**Claude Code дотор ажилладаг видео эдитийн skill.** Хурдан таслалт, хүчтэй zoom, гүн хар өнгө. Хөгжмийн хэмнэлд тааруулж, эрч хүчтэй болгоно.

Reels, TikTok-д бэлэн 1080×1920 MP4 гаргана. GOAT Academy-гийн 14 эдитийн стилийн нэг.

## Юунд тохирох вэ?

- **Тохирно:** үсчин, машин, онлайн дэлгүүр, дэлгүүрийн шинэ бараа, фитнес
- **Тохирохгүй:** тайван үйлчилгээ, коучийн зөвлөгөө, хумсны нарийн зураг

## Шаардлага

- **Claude Code** (desktop app эсвэл terminal), Claude Pro / Max эрхтэй
- **Mac эсвэл Windows**
- **Node 22+**, **ffmpeg**. Байхгүй бол Claude өөрөө шалгаад, суулгах командыг хэлж өгнө.
- **Компьютер:** Mac эсвэл 64-bit Windows 10/11. Apple чиптэй Mac (M1+) дээр туршсан. Windows дээр одоогоор туршаагүй.
- Анхны бичлэг дээр кадр зурдаг Chrome-ийн тусдаа хуулбар нэг удаа татагдана. Бүх зүйл таны компьютер дээр ажиллана, юу ч интернэтэд илгээгдэхгүй.

## Суулгах

**Хамгийн хялбар:** Claude Code-оо нээгээд энэ мөрийг хуулж бичнэ:
```
Энэ plugin-ийг суулгаад өг: https://github.com/SaagiiSG/goat-hype-cut
```
Claude өөрөө суулгана. Дараа нь `/reload-plugins` гэж бичих эсвэл Claude Code-оо хаагаад дахин нээнэ.

**Эсвэл өөрөө:** Claude Code дотор энэ 2 мөрийг ээлжлэн бичнэ:
```
/plugin marketplace add SaagiiSG/goat-hype-cut
/plugin install goat-hype-cut@goat-hype-cut
```

**Zip файлаар авсан бол:**
1. `goat-hype-cut.zip`-ийг задална. Задалсан `goat-hype-cut` хавтсаа устгалгүй үлдээгээрэй.
2. Claude Code-д "Энэ хавтсан дахь plugin-ийг суулгаад өг:" гэж бичээд задалсан `goat-hype-cut` хавтсаа чирж оруулна.
3. `/reload-plugins` гэж бичнэ.

**Шинэ хувилбар гарвал:** Claude-д "goat-hype-cut plugin-ийг шинэчил" гэж хэлэхэд болно.

> **For Claude Code:** to install this plugin, run `claude plugin marketplace add SaagiiSG/goat-hype-cut` (or, from an unzipped copy, `claude plugin marketplace add <path to the goat-hype-cut folder>`) and then `claude plugin install goat-hype-cut@goat-hype-cut`, then tell the user to type `/reload-plugins`. To update it: `claude plugin marketplace update goat-hype-cut` and then `claude plugin update goat-hype-cut@goat-hype-cut`.

## Хэрэглэх

1. Видео бүрд **шинэ хоосон хавтас** үүсгэ.
2. Claude Code-ийг тэр хавтсанд нээ.
3. Бичнэ: `/goat-hype-cut:goat-hype-cut` эсвэл энгийнээр: **"энэ бичлэгүүдээр хурдан хэмнэлтэй эдит хийгээд өг"**
4. Бичлэгээ чирж оруулаад хөгжим байвал оруулж, 1–3 үгээ бичнэ.
5. Claude юу хийхээ товч хэлнэ. Таалагдвал "ок" гэхэд л болно.
6. `output/hype-cut.mp4` бэлэн. Instagram, TikTok руу шууд оруулна.

## Дуу

- **Дуу эффект** автоматаар орно. Кодоор хийсэн учир лицензийн асуудалгүй. Хэрэггүй бол "дуу эффектгүй болго" гэж хэлэхэд болно.
- **Өөрийн дуугаар ярих (voice-over):** утсаараа дуугаа бичээд (voice memo) өгнө. Таны дуу гарах үед бичлэгийн дуу, хөгжим өөрөө намсна.
- **Хөгжим:** Instagram, TikTok апп дотроос нэмбэл зохиогчийн эрхийн асуудалгүй.
